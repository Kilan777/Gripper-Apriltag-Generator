Same 4-panel plate, but each part is pre-assigned to filament slot 1 (background) or 2 (ink) in the file itself — no manual per-object filament assignment needed after import into Bambu Studio / Orca Slicer. Slot numbers only pick which AMS filament a part uses, not an actual color — if it comes in backwards, either flip the checkbox above before re-downloading, or just swap what's loaded in slot 1 vs 2 in Bambu Studio.
